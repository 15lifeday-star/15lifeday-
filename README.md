# 15Lifeday

A responsive, browser-based recreation of the 15Lifeday reference UI. The app is
implemented with plain HTML, CSS, and JavaScript and has no install step.

## Run locally

From the repository root, start a static server:

```sh
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). User-created journal
entries, goals, habits, and finance records are stored in this browser.
